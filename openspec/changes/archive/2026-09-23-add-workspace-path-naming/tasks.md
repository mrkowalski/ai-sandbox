Scope beyond this change: at container start only the entrypoint's six iptables checks actually execute. Blocked egress, git push, the read-only rootfs, the host-only guard, the `.git` bind, and the npm cache are never exercised automatically — `verify.sh` is a manual tool in practice. That contradicts the repo's stated design that guarantees are checked at every start, and is a separate change: it is not this one's to fix, and the fix belongs in the entrypoint, where the firewall's own enforcement already lives.
